Cumulative distribution of accepted-upload-to-approval time
for CMPU vet-diet \texttt{CUSTOMER\_UPLOAD} first-order lines with current
status D. Elapsed time is the latest recorded approval timestamp minus the
selected accepted entity's state-change timestamp. The curve shows only
nonnegative gaps from 0 through 60 seconds inclusive and is normalized to that
subset; gaps above 60 seconds are omitted. Each distinct matched first-order
line counts once.
