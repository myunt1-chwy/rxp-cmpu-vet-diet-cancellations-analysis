* Cohort definition

of the eligible original/reorder pair, with different prescription IDs.
Warehouse upload entities match both prescription and customer IDs. Preserve
the query's upload cutoff and source audits. Expanding prescription IDs already
stored in warehouse upload entities does not supply an external cohort.

identifier lists. Review its target-owned =src/sql/= source;
