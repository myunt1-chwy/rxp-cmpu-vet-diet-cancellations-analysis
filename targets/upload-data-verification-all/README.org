#+TITLE: upload-data-verification-all

This existing Make command coordinates outputs for multiple report paragraphs; it does not add a document section.

Run =make upload-data-verification-all CACHED=1= to rebuild with retained data. Source is owned under =src/python/=; queries and templates used only by this command are in =src/sql/=. Existing arguments, output paths and cache checks are preserved.

Fresh verification queries resolve Parquet and SQL-history paths through the artifact ownership registry before invoking the SQL runner. The runner receives repository-relative target-owned paths, matching the appendix readers.
