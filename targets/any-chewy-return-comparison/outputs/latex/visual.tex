\textit{Shared follow-up rules:} Match the same numeric customer ID only; include all Chewy product categories and any pet or product. Use a different order
placed strictly after the matched cancellation through the indicated day, inclusive.
Follow-up orders come from \texttt{EDLDB.ECOM.ORDER\_LINE}; no later prescription, approval-channel, prescription-source, vet-diet, product or pet restriction applies.
Exclude the entire later order if any line or order has status X, a recorded cancellation reason,
a cancellation timestamp or unknown line status. Statuses and prescription channels reflect
the extraction snapshot. All windows require complete follow-up through 2026-10-28 00:00 UTC.
Each customer, order and matching physical line counts once per window, despite repeated
anchor associations. Windows overlap and must not be added. Net sales sum \texttt{NET\_SALES} on all qualifying ECOM order lines once per physical order line, preserving zero and negative amounts. Exact source duplicates collapse and conflicting line values fail validation; missing sales make totals incomplete.
Sales can be recorded after the placement window and do not prove recovered revenue.
