#+TITLE: Root directory retirement validation

* Layout
- Former =src/ignore/= is now =playground/=. Playground contents are preserved and excluded from maintained Python/SQL checks.
- Root =src/= and =data/= are removed, including compatibility filesystem links. Python callers use =shared.python= and SQL readers use the canonical source registry.
- Retained datasets and generated artifacts belong to =targets/<owner>/=. Historical audits are retained under =targets/report/data/=. Distinct historical files are never overwritten by a conflicting destination.
- The report owns the retained LaTeX assembly under =targets/report/src/latex/retained/=. Existing paragraph adapters still consume those fragments; authored paragraph content remains in each target's =src/latex/=. This migration does not redesign those adapters.
- Only the published PDF remains under root =outputs/reports/pdf/=. The preview writes to the report target, not to the published copy.
- Historical logical path strings remain in some generators and evidence manifests. =shared/artifact-ownership.yaml= and =shared/paths.py= route them without root-directory links; recorded cache identities are not rewritten.

* Verification
- The staged SQL hook explicitly excludes playground files while still disregarding ignore patterns for maintained SQL. A regression test verifies both cases; commit hooks pass.
- Full suite: 639 tests passed and 16 subtests passed.
- Ruff lint/format and =git diff --check= pass.
- Source validator: 63 modules, 57 canonical queries and 22 extracted templates. Hierarchy validator: 65 targets and 34 paragraph pipelines.
- All 34 paragraph artifacts regenerate from retained files without root compatibility directories. =make combined-follow-up-table= succeeds.
- =make preview-target-report= builds the retained presentation PDF successfully. The published PDF is unchanged.
- File moves verify SHA-256 before and after relocation. The local manifest at =targets/report/data/root-layout-migration.json= records the later migration batches; 176 retained data/SQL evidence records were rechecked after rendering. It is not a complete inventory of all earlier moved files.
- No warehouse data was refreshed. =make report= reaches the existing financial-baseline SQL fingerprint mismatch and stops without fetching data. The preview is not a substitute for resolving that provenance issue.
