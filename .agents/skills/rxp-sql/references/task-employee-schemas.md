# Task lifecycle and employee schemas

Use these source tables when task timing needs employee role, warehouse, or shift context.

## Approved relationship

`EDLDB.PET_HEALTH_ANALYTICS_SANDBOX.FCT__TASKS_LIFECYCLE.USER_ID` joins to `EDLDB.BT_PET_HEALTH_RX_OPERATIONS.RX_DIM_EMPLOYEES.EMPLOYEE_KYRIOS_ID`.

The employee table contains reporting snapshots. Before joining it to task-grain data, retain the latest row per `EMPLOYEE_KYRIOS_ID`, ordered by `REPORT_DATE DESC NULLS LAST`, `LAST_UPDATE_TIME DESC NULLS LAST`, and `EMPLOYEE_KEY DESC NULLS LAST`. Cast `EMPLOYEE_KYRIOS_ID` to `VARCHAR` to match lifecycle `USER_ID`.
