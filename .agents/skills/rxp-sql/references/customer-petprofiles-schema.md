## Prescription joins

Use the following user-confirmed joins to
`BT_HCA_HCDM.RXP_PRESCRIPTIONS`:

```sql
pet_profiles.PETPROFILE_ID = prescriptions.PET_ID
pet_profiles.PETPROFILE_CUSTOMER_ID = prescriptions.CUSTOMER_ID
```

Neither profile key is declared unique in the supplied metadata. Check the
intended grain and deduplicate or aggregate before calculating prescription- or
customer-level metrics.
